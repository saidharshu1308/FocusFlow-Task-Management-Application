# FocusFlow Backend API

A RESTful backend built with Node.js, Express, and MySQL using `mysql2/promise`.

## Getting Started

### 1. Prerequisites
- Node.js installed
- MySQL Server running locally

### 2. Database Setup
1. Open MySQL workbench or CLI.
2. Run the SQL statements inside `schema.sql` to set up tables.

### 3. Installation
```bash
npm install
